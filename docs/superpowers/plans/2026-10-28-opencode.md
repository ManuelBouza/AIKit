# Plan de implementación: OpenCode

**Objetivo:** ejecutar trabajo delegado con modelos gratuitos de OpenCode, reservando Codex para coordinación y verificación.
**Arquitectura:** skill y adaptador Python estándar; CLI oficial v2, política de proveedor del proyecto y lista explícita de modelos.
**Especificación:** `docs/superpowers/specs/2026-10-28-opencode-design.md`.
**Método:** ejecución delegada a OpenCode según la preferencia de Manuel; Codex comprueba resultados e instala. El método sustituye las implementaciones mediante subagentes nativos de pago.

## Restricciones

- Python 3.10+, biblioteca estándar, Windows primero.
- Ninguna ejecución delegada a `openai/*` ni alternativa automática de pago.
- Un intento por llamada, modelo explícito y timeout acotado.
- La skill es autocontenida y reproducible; documentación en español.

## Foco de revisión

Argumentos que contienen espacios o símbolos de shell; errores en JSON con salida cero; modelos ausentes; timeout con procesos hijos; instalación sobre una carpeta existente. Verificar con pruebas locales y una ejecución real, sin interpretar ausencia de coste como coste cero.
