- (capability) CAP-1 Instalar preferencias go y Context7 en perfil Codex conservando instrucciones ajenas.
- (capability) CAP-2 Actualizar versiones y repetir sin duplicar cambios, mostrando resultado y respaldo.
- (capability) CAP-3 Mostrar cambios y detectar conflictos antes de escribir ambos bloques.
- (constraint) Respetar CODEX_HOME, override global, BOM, marcadores, enlaces, junctions y modificaciones concurrentes; respaldar antes de sustituir.
- (constraint) Validar primero perfiles ficticios; no alterar el perfil real durante implementación ni invocar OpenCode.
- (constraint) Separar Delegating to OpenCode y conservar complementos y configuración ajenos.
- (question) Nombre y registro npm, versión mínima de Node y plataformas adicionales a Windows pendientes.
- (assumption) La versión instalada se identificará de forma verificable sin exponer información privada.
- (event) Autovalidación: coherencia y preservación revisadas; fuentes de detalle adoptadas; contenido ceremonial omitido.
