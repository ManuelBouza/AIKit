# Empaquetado de AIKit — plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Goal:** Distribuir la skill y el MCP como complemento privado instalable.
**Architecture:** Manifiesto y catálogo nativos, núcleo existente, runtime uv.
**Tech Stack:** JSON, Python tipado, uv, pytest y Codex CLI.
**Spec:** `docs/superpowers/specs/2026-10-29-plugin-design.md`.

## Restricciones

Implementación delegada a OpenCode; coordinación/verificación nativas. Workers
no redelegan ni modifican configuración personal. Sin hooks ni nueva skill.
Conservar CLI, políticas y pruebas. No push ni publicación. Entorno de instalación
temporal bajo `.aikit/`; no cambiar el resto de plugins.
