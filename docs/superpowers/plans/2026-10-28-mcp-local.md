# MCP local de AIKit — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Exponer el adaptador existente como dos herramientas MCP locales.

**Architecture:** SDK oficial para STDIO; núcleo compartido entre CLI por archivo
y MCP por texto, sin duplicar políticas. El coordinador elige modelo/esfuerzo.

**Tech Stack:** Python tipado, SDK MCP 1.x, uv, pytest, Ruff y mypy.

**Spec:** `docs/superpowers/specs/2026-10-28-mcp-local-design.md`.

## Global Constraints

- Conservar CLI y sus 161 pruebas, políticas y selección explícita.
- No inferencia real en tests; no configuración personal durante implementación.
- Sin HTTP, trabajos persistentes ni garantía de cancelación activa.
- Desarrollo debe instalar SDK para probar MCP; CLI continúa con stdlib.

## Review Focus

stdout contaminado, argumentos de otra tarea y timeout cliente insuficiente.
