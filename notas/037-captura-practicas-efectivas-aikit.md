# Recopilar prácticas efectivas como candidatas para AIKit

Fecha: 2026-11-15.
Estado inicial: Pendiente de debatir.

## Idea

Agregar un procedimiento que permita detectar durante el trabajo en este
proyecto configuraciones, preferencias, procedimientos y buenas prácticas que
funcionan y que podrían incorporarse a AIKit como preferencias o skills.

Cuando se identifique una práctica efectiva, registrar una nota para evaluar su
incorporación futura. Conservar el contexto de uso, el beneficio observado y la
evidencia disponible, sin presentar como comprobado lo que aún sea una hipótesis.

## Aspectos pendientes de definir

- Si el mecanismo debe ser una instrucción, una skill o una combinación, y cómo
  detectar candidatos durante el trabajo sin añadir un coste excesivo.
- Qué evidencia permite considerar efectiva una práctica y qué alcance tiene
  ese resultado; distinguir lo específico del proyecto de lo reutilizable.
- Cómo evitar notas duplicadas y enlazar o ampliar una nota existente cuando
  corresponda.
- Cómo decidir posteriormente si el candidato encaja como preferencia, skill o
  capacidad ya cubierta por herramientas existentes.

## Ampliación — 2026-11-15

Valorar la posibilidad de usar una skill para guiar el proceso de resolución de
problemas mediante la consulta de documentación oficial y fuentes especializadas
fiables. Revisar primero la cobertura de las skills existentes para determinar
si conviene reutilizar alguna o si hay una carencia que justifique crear otra.
Esta posibilidad queda pendiente de evaluación.

## Relaciones y alcance

- [007 — Separar delegación de AIKit](007-separar-delegacion-de-aikit.md):
  respetar la separación entre instrucciones, skills y herramientas.
- [016 — Investigar antes de experimentar](016-investigacion-antes-de-experimentar.md)
  y [036 — Investigación antes de pruebas](036-reforzar-investigacion-antes-de-pruebas.md):
  relacionar la posible skill con la regla de investigación y su refuerzo.

Detectar y registrar una práctica no autoriza incorporarla, instalarla ni cambiar
las preferencias del usuario automáticamente. Esta nota recoge la idea del
procedimiento; no lo implementa ni lo activa.
